The idea for this space is to hold the longer-form stories that don't fit into a resume bullet or a case study card: how a decision actually got made, what a rollout looked like from the inside, lessons from a launch that didn't go to plan, or a point of view on AI product management that's too opinionated for the main site.

## How to add a new post

1. Create a new file in `content/blog/` named `your-post-slug.mdx`.
2. Add frontmatter at the top (see this file for the exact fields: `title`, `date`, `excerpt`, and optional `tags`).
3. Write the body in Markdown/MDX below the frontmatter.
4. It shows up automatically on `/blog` and gets its own page at `/blog/your-post-slug` — no other code changes needed.
